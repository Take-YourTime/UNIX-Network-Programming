# UNIX Network programming

UNIX Network programming course assignments at NSYSU in spring, 2026  

Textbook Link: [The Linux Programming Interface](https://broman.dev/download/The%20Linux%20Programming%20Interface.pdf)

## Overview

以下是所有本課程作業的內容簡介：

| Assignment | Topic / Content | Description |
| :---: | --- | --- |
| **HW1** | **Introduction** | 課程環境建置與基礎概念 |
| **HW2** | **File I/O** | Ch4 實作練習 (`tee` 與 `cp` 指令實作) |
| **HW3** | **File Buffering** | Ch13 實作練習 (檔案操作實作) |
| **HW4** | **Shell (Part 1)** | 基礎命令列解析、內建指令執行實作 |
| **HW5** | **System & Process** | Ch12 實作練習 (讀取系統與行程資訊) |
| **HW6** | **Shell (Part 2)** | 新增 Pipeline (`\|`) 與 I/O 重新導向支援，以及基礎字典查詢 |
| **HW7** | **Pipes & FIFOs** | Ch44 實作練習 (行程間通訊) |
| **HW8** | **Signals** | Ch22 實作練習 (`sigsuspend` 與 `sigwaitinfo` 應用) |
| **HW9** | **Semaphores** | System V / POSIX Semaphores 號誌機制實作 |
| **HW10** | **Socket Programming** | Client/Server 架構與 Non-blocking I/O 實作 |
| **HW11** | **ZeroMQ (Part 1)** | IPC/TCP 伺服器架構與 Worker 模型 |
| **HW12** | **ZeroMQ (Part 2)** | 進階訊息佇列機制實作 |
| **HW13** | **ZeroMQ (Part 3)** | Broker 與 Dispatcher 派發模式實作 |
